# HouseholdGoodsIS — АИС «Учёт бытовых товаров»

WPF-приложение (.NET 10) для магазина бытовой техники в стиле сайта DNS:
витрина с категориями и карточками, корзина и оформление заказов, поставки,
продажи, клиенты, пользователи и отчёты.

## Запуск

1. Развернуть базу данных `household_goods_db` скриптами из `04_База_данных`.
2. Открыть `HouseholdGoodsIS.slnx` в Visual Studio или выполнить:

```
dotnet run
```

## Учётные записи

- `admin / admin123` — администратор;
- `manager / manager123` — менеджер.

## Состав проекта

- `Models/` — модели предметной области;
- `Data/` — доступ к PostgreSQL через Npgsql;
- `Services/` — сервисы диалогов и редакторов;
- `ViewModels/` — модели представления (MVVM);
- `Views/` — окна, страницы и окна редактирования;
- `Resources/Themes/Theme.xaml` — стиль Windows 10;
- `images/` — изображения товаров.

## Скриншоты

`HouseholdGoodsIS.exe --screenshots <каталог>` — служебный режим формирования
