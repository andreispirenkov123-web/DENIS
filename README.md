# DENIS — АИС «Учёт бытовых товаров»

WPF-приложение (.NET 10) для магазина бытовой техники **DENIS**: витрина с категориями и карточками товаров, корзина и оформление заказов с выбором магазина самовывоза, поставки, продажи, складской учёт, клиенты, сотрудники и отчёты.

## Стек

- C# / .NET 10, WPF, MVVM;
- PostgreSQL 18, Npgsql;
- ERD в нотации IDEF1X, словарь данных;
- тест-кейсы и руководство по стилю.

## Запуск

1. Развернуть базу `household_goods_db` из `Бд/dump_household_goods_db.sql` или скриптов `Бд/01…09`.
2. Открыть `HouseholdGoodsIS.slnx` в Visual Studio или выполнить:

```bash
dotnet run
```

## Учётные записи

- `admin / admin123` — администратор;
- `manager / manager123` — менеджер.

## Состав проекта

- `Models/` — модели предметной области;
- `Data/` — доступ к PostgreSQL через Npgsql;
- `Services/` — сервисы диалогов и редакторов;
- `ViewModels/` — модели представления (MVVM);
- `Views/` — окна, страницы и окна редактирования;
- `Resources/Themes/Theme.xaml` — словарь стилей;
- `Resources/Images/` — логотип и изображения;
- `images/` — изображения товаров.

## Документация

Документы проекта находятся в папке `Бытовые Товары` рабочего каталога: отчёт УП.07, курсовая, словарь данных, руководство по стилю, тест-кейсы, ERD и скриншоты.
